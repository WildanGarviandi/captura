# Captura

A wrapper to wf-recorder to do screen capturing utility written in Rust gui using [iced](https://github.com/iced-rs/iced).

## How to Run

To run Captura, you'll need to have Rust and Cargo installed.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/WildanGarviandi/captura.git
    cd captura
    ```
2.  **Build and run the application:**
    ```bash
    cargo run --release
    ```
3.  **To Install**
    you can copy the binary to `/usr/bin` or put somewhere that you can make `.desktop` file out of it for convinient.

## Prerequisites

*   **Rust and Cargo**: If you don't have Rust installed, you can get it from [rustup.rs](https://rustup.rs/).

*   **wf-recorder**: [wf-recorder](https://github.com/ammen99/wf-recorder) thank you for such amazin tool
